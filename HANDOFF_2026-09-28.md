# Передача задачи: Telegram-автопубликация вакансий

## Цель и требования пользователя

- Автоматически собирать московские вакансии повара и кондитера с открытого API «Работы России».
- Раскладывать вакансии в соответствующие темы Telegram.
- В каждой публикации обязательно одно сообщение Telegram: картинка и подпись с текстом вместе.
- Использовать хештеги/блоки из шаблона для должности, описания, зарплаты, графика, условий, обязанностей, требований и контактов.
- Внизу каждого объявления ставить ссылку на исходную вакансию. Переносить доступные телефон/email; не придумывать отсутствующие сведения.
- Система должна быть бесплатной и работать на этом компьютере, когда он включён. Генерация карточки локальная, токены ИИ не используются.

## Важные ограничения

- Подпись фото ограничена 1024 символами в Telegram Bot API. При превышении нужно сокращать длинные описательные блоки, сохраняя зарплату, контакты и прямую ссылку на вакансию.
- Публикация идёт с паузой 4 секунды между вакансиями. Полная очередь на сотни объявлений отправляется постепенно.
- Автопубликация `automation_enabled=false`; массовая отправка не запущена.
