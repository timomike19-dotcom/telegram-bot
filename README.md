# Автопубликация вакансий из «Работы России»

## Что делает система

- При первом запуске загружает активные вакансии Москвы по названиям должности «повар» и «кондитер».
- Каждые 10 минут проверяет изменения через открытый API «Работы России». API работает без заявки и токена.
- Публикует повара в тему `Повар`, кондитера — в тему `Кондитер`.
- Отправляет фото и текст объявления одним сообщением Telegram. Длинное описание сокращается до лимита подписи к фото, сохраняя в первую очередь должность, зарплату, контакты и ссылку на источник.
- Собирает текст по образцу из `vacancy_template.txt`. Контакты выводятся, если они есть в записи; если нет — остаётся ссылка на карточку вакансии.
- Добавляет ссылку `trudvsem.ru` как источник данных.
- Перед отправкой сохраняет объявление в SQLite. Если компьютер выключен, база и очередь остаются; после запуска бот продолжает работу и получает новые записи.
- Не использует OpenAI, платные API или лимитируемые текстовые токены.

API «Работы России» ограничивает ответ 100 записями на страницу и описывает общий предел 10 000 записей на запрос. Бот листает страницы по двум поисковым запросам, удаляет дубликаты по ID и ежедневно перепроверяет полный список. Публикации идут с паузой не менее четырёх секунд между объявлениями. Каждая вакансия отправляется одним `sendPhoto`-сообщением с подписью, без отдельного сообщения с текстом.

## Изображение к каждому объявлению

Бот создаёт локальную авторскую графическую карточку вакансии: отдельный дизайн для повара или кондитера, должность, зарплата и город. Картинка собирается из локальных фигур и шрифтов через Pillow; никакие внешние фото, генеративные API или токены не нужны. Это карточка-иллюстрация, не фотореалистичная ИИ-фотография. Файлы карточек сохраняются в `data/vacancy_images/`.

«Шедеврум» не подключён: в найденных официальных условиях нет документированного API для такого сценария; коммерческое использование созданных материалов требует предварительного согласования с Яндексом. Если нужен именно реалистичный ИИ-снимок, нужен отдельный локальный генератор с подходящей видеокартой или отдельное разрешение/сервис.

## Текущий тестовый режим

- Группа: `-1003908484434`.
- Тема `Повар`: `thread_id=2`.
- Тема `Кондитер`: `thread_id=3`.
- Город: Москва (`7700000000000`).
- `automation_enabled` пока `false`, поэтому автоматические реальные объявления не отправляются до проверки тестовой группы.
- Основной канал не выбран в конфиге. Перенос делается после успешной проверки теста и настройки прав бота в целевом канале.

В `.env` должен лежать `TELEGRAM_BOT_TOKEN`. Файл уже используется ботом; не публикуйте его, не присылайте в чат и не коммитьте в Git.

## Проверки и запуск

Проверка соединения с источником и загрузка объявлений в локальную очередь, без публикации:

```powershell
& 'C:\Users\timos\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' telegram_bot.py --check-work-russia
```

Тест изображения и форматирования в тестовой теме (отправит одно демо-сообщение с фото и текстом):

```powershell
& 'C:\Users\timos\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' telegram_bot.py --demo-topic Повар
```

Постоянный локальный запуск:

```powershell
& 'C:\Users\timos\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' telegram_bot.py
```

Чтобы бот запускался после входа в Windows, выполните в PowerShell из этой папки:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\register_windows_task.ps1
```

Задача создаётся для текущего пользователя и перезапускает бота после сбоя. Компьютер должен оставаться включённым и не уходить в сон; при выключении отправка ждёт следующего входа в Windows. Бот не публикует быстрее установленной паузы и в первую очередь досылает накопленную очередь.

Логи — `telegram_bot.log`. База очереди и история — `vacancies.sqlite3`. Не удаляйте базу, если нужно сохранить очередь и дедупликацию.

## Источник данных и атрибуция

Портал предоставляет вакансии через открытые данные и требует ссылку на `trudvsem.ru` при копировании информации. Полное описание выдачи, региональный поиск, пагинация и фильтр `modifiedFrom` описаны в разделе API портала. Бот не открывает учётную запись и не обходит CAPTCHA.
